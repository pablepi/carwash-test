# Шаблон Базы Данных для Автомойки (Яндекс Таблицы / Google Таблицы / Excel)

Данная структура разработана для использования онлайн-таблиц (Яндекс Документы, Google Sheets, MS Excel) в качестве полноценной базы данных для сайта автомойки/детейлинга.

---

## Структура листов в таблице

Рекомендуется создать 5 листов со следующими названиями:
1. **`Записи`** — главный операционный журнал всех бронирований.
2. **`Клиенты`** — автоматическая CRM-база клиентов.
3. **`Услуги`** — каталог услуг и тарифная сетка.
4. **`Боксы`** — посты мойки и график работы.
5. **`Настройки`** — системная синхронизация настроек сайта.

---

## Лист 1: `Записи` (Основной журнал бронирований)

Сюда автоматически попадают все заявки с сайта, а также ручные записи администратора.

| Колонка | Заголовок столбца | Тип данных | Пример значения | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **A** | `ID записи` | Текст | `AD-1042` | Уникальный номер бронирования |
| **B** | `Дата` | Дата (YYYY-MM-DD) | `2026-11-20` | Дата записи клиента |
| **C** | `Время` | Время (HH:mm) | `14:30` | Забронированный слот |
| **D** | `Клиент` | Текст | `Александр Смирнов` | Имя клиента |
| **E** | `Телефон` | Текст | `'+79991234567` | Номер телефона (сохраняется как текст с `'`) |
| **F** | `Автомобиль` | Текст | `BMW X5` | Марка и модель авто |
| **G** | `Госномер` | Текст | `А123МР77` | Номерной знак |
| **H** | `Категория` | Текст | `Кроссовер` | Седан / Кроссовер / Внедорожник |
| **I** | `Услуга` | Текст | `Комплексная мойка` | Выбранный комплекс |
| **J** | `Стоимость` | Число (₽) | `2500` | Сумма к оплате |
| **K** | `Бокс` | Текст | `Бокс 1` | Назначенный бокс |
| **L** | `Статус` | Текст | `pending` | `pending` (Ожидает) / `in_progress` (В работе) / `completed` (Завершена) / `cancelled` (Отменена) |
| **M** | `Токен отмены` | Текст | `tok_a9f4c1` | Секретный токен для страницы «Моя запись» |
| **N** | `Дата создания` | Дата-время | `2026-11-19 10:25:00` | Время создания заявки на сайте |
| **O** | `Заметки` | Текст | `Турбосушка, без химии на диски` | Пожелания клиента |

> [!TIP]
> Для столбца **L (`Статус`)** в Яндекс Таблицах или Excel рекомендуется включить **«Проверку данных» (Выпадающий список)** со значениями: `pending, in_progress, completed, cancelled`.
> Для столбца **E (`Телефон`)** формат ячеек должен быть строго **«Текстовый»**, чтобы знак `+` не вызывал ошибки формулы.

## Лист 2: `Клиенты` (Автоматическая CRM)

Этот лист позволяет вести историю постоянных клиентов. Данные по визитам и суммам рассчитываются автоматически по формулам из листа `Записи`.

| Колонка | Заголовок столбца | Тип | Формула / Пример | Назначение |
| :--- | :--- | :--- | :--- | :--- |
| **A** | `Телефон` | Текст | `+7 (999) 123-45-67` | Уникальный идентификатор клиента |
| **B** | `Имя` | Текст | `Александр` | ФИО |
| **C** | `Автомобиль` | Текст | `BMW X5 [А123МР77]` | Основной авто |
| **D** | `Кол-во визитов` | Число | `=СЧЁТЕСЛИ(Записи!E:E; A2)` | Подсчитывает число выполненных визитов |
| **E** | `Сумма (LTV)` | Число (₽) | `=СУММЕСЛИ(Записи!E:E; A2; Записи!J:J)` | Вся выручка по клиенту |
| **F** | `Скидка %` | Число | `10` | Персональная скидка клиента |
| **G** | `Последний визит` | Дата | `=МАКСЕСЛИ(Записи!B:B; Записи!E:E; A2)` | Дата недавнего посещения |
| **H** | `Заметки` | Текст | `Любит кофе, постоянный клиент` | Комментарии мойщиков |

## Лист 3: `Услуги` (Прайс-лист)

Справочник всех доступных услуг автомойки:

| ID услуги | Название | Длительность (мин) | Седан (₽) | Кроссовер (₽) | Внедорожник (₽) | Бейдж | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `service-express` | Экспресс мойка кузова | 30 | 900 | 1100 | 1300 | Экспресс | Активна |
| `service-standard` | Стандартная 2-фазная мойка | 45 | 1600 | 1900 | 2200 | Хит | Активна |
| `service-complex` | Комплекс Премиум + Салон | 60 | 2800 | 3300 | 3800 | Премиум | Активна |
| `service-detailing` | Детейлинг химчистка салона | 180 | 8000 | 9500 | 11000 | VIP | Активна |

## Лист 5: `Настройки` (Синхронизация сайта)

Используется для хранения резервной копии конфигурации сайта (дизайн, цвета, контакты, соцсети):

| Параметр | Значение |
| :--- | :--- |
| `site_config_json` | `{"branding": {"name": "AquaDrive", ...}, "theme": {"mode": "dark", ...}}` |
| `last_synced_at` | `2026-11-19 10:30:00` |
