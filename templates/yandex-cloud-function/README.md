# Инструкция по переходу с Google Таблиц на Яндекс

В экосистеме Яндекса (Яндекс Документы / Яндекс Диск) веб-таблицы не имеют встроенного движка публичных макросов, как Google Apps Script. 
Поэтому для Яндекс Таблиц используется **Яндекс Облако (Yandex Cloud Functions)** — официальный, надежный и **100% бесплатный** способ (бесплатный тариф включает **1 000 000 вызовов функции каждый месяц**).

---

## 4 простых шага для подключения Яндекс:

### Шаг 1. Создайте таблицу в Яндекс Документах
1. Откройте [Яндекс Диск](https://disk.yandex.ru).
2. Нажмите **«Создать» → «Таблицу»** (или загрузите файл `templates/bookings_template.csv`).
3. Назовите файл, например: `База_Автомойки.xlsx`.
4. Создайте колонки согласно инструкции в [`templates/DATABASE_SCHEMA.md`](../DATABASE_SCHEMA.md).

---

### Шаг 2. Создайте бесплатную функцию в Яндекс Облаке
1. Перейдите в консоль [Yandex Cloud](https://console.yandex.cloud/).
2. В левом меню выберите **Cloud Functions** (Бессерверные функции).
3. Нажмите кнопку **«Создать функцию»**:
   - Имя: `carwash-webhook`
   - Нажмите **«Создать»**.
4. В открывшемся окне редактора:
   - **Среда выполнения:** выберите `Python 3.11` или `Python 3.12`.
   - **Точка входа:** укажите `index.handler`.
   - **Таймаут:** `5` сек.
   - **Память:** `128 МБ`.
5. Скопируйте весь код из файла [`templates/yandex-cloud-function/index.py`](./index.py) и вставьте в редактор кода в файл `index.py`.
6. Нажмите **«Создать версию»** (вверху справа).

---

### Шаг 3. Сделайте функцию публичной и скопируйте URL
1. Перейдите во вкладку **«Обзор»** созданной функции.
2. В блоке параметров включите переключатель **«Публичная функция»** (чтобы сайт мог присылать заявки).
3. Скопируйте появившуюся **«Ссылку для вызова»** (вид: `https://functions.yandexcloud.net/d4e...`).

---

### Шаг 4. Вставьте ссылку в админку сайта
1. Откройте админ-панель вашего сайта автомойки.
2. Перейдите во вкладку **«Настройки» → «База данных»**.
3. Вставьте скопированную ссылку `https://functions.yandexcloud.net/...` в поле URL.
4. Нажмите **«Проверить связь»** и затем **«Сохранить»**.

Готово! Теперь все новые записи с сайта будут моментально обрабатываться через сервис Яндекс.

---

### Опционально: Мгновенные уведомления в Telegram
Если вы хотите, чтобы при каждом бронировании вам или администраторам в Telegram сразу приходило красивое сообщение с деталями записи (авто, имя, телефон, сумма, выбранная услуга):
1. В настройках функции в Yandex Cloud добавьте две **Переменные окружения**:
   - `TELEGRAM_BOT_TOKEN` — токен вашего бота от `@BotFather`.
   - `TELEGRAM_CHAT_ID` — ID вашего чата или рабочей группы.
2. Нажмите «Создать версию». Теперь каждая новая запись мгновенно дублируется в Telegram!
